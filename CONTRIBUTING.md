# Contributing

Thanks for considering contributing.

## Templates

Templates live in the `/templates` directory and should follow the existing structure and formatting rules described in the README.

Keep templates simple and focused. Avoid unnecessary or overly broad ignore rules.

## License

By submitting a pull request that adds or modifies templates, you agree to release those changes under CC0 (public domain).

This ensures all templates remain free to use, modify, and distribute without restriction.
